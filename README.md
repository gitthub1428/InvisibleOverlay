# Floating Hub

A movable floating bubble with a mini web panel for ChatGPT and Gemini.

## 📲 Download

**[⬇️ Download the latest APK](https://github.com/gitthub1428/InvisibleOverlay/releases/latest/download/app-debug.apk)**

[View all versions / releases](https://github.com/gitthub1428/InvisibleOverlay/releases)

## Features
- Movable floating bubble
- Mini browser panel with ChatGPT and Gemini buttons
- Android **Display over other apps** permission

## Install
1. Download the APK above.
2. Install it (allow installs from this source if Android prompts).
3. Open Floating Hub and grant overlay permission.
4. Start the floating window.

This is a visible overlay, not a recorder-evasion tool.

## Versions
Each successful build publishes a versioned GitHub Release with the APK attached. The download link above always points to the latest release.
